# Stack Tecnológico

## Frontend
- **Framework:** React 18
- **Herramienta de construcción:** Vite
- **Lenguaje:** JavaScript (ESM)
- **Puerto:** 3000

## Backend
- **Entorno:** Node.js
- **Framework:** Express
- **Middleware:** CORS, express.json()
- **Puerto:** 3001

## Base de Datos
- **Tipo:** En memoria (In-memory)
- **Implementación:** Objeto JavaScript volátil en el servidor.

## Estructura de Carpetas
- `/frontend`: Aplicación cliente React.
- `/backend`: API REST de Node.js.
